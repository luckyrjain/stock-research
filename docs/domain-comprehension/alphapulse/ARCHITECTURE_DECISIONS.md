# Architecture Decisions

No formal `docs/adr/*.md` or `ADR-*.md` files exist in this repository (`find . -iname "*ADR*"`
returns only unrelated third-party package paths). The decisions below are reconstructed from the
root `CLAUDE.md` "Architectural Constraints" section (a committed, in-repo design doc, capped at
MEDIUM confidence per this engagement's evidence-precedence rules) and cross-checked against the
actual implementation by this engagement's six research agents — each row's Confidence column
reflects whether independent code verification raised it to HIGH.

| ID / title | Status | Source (path) | Summary | Code aligned? | Confidence |

| Monolith over microservices | Accepted, binding | root `CLAUDE.md` § Architectural Constraints | Single FastAPI + Next.js deployable, no service split; explicitly rejects a service mesh/API gateway. | Yes — confirmed by every dispatched agent; no evidence of a second deployable service anywhere in the repo | HIGH |
| PostgreSQL as the only datastore | Accepted, binding | root `CLAUDE.md` | No Cassandra/ClickHouse/TimescaleDB/MongoDB/data lake/feature store. | Yes — confirmed: 23 tables, one shared `MetaData()`, SQLAlchemy Core (not ORM) | HIGH (backend-core agent read `db/models.py:3-9` directly) |
| Redis strictly optional | Accepted, binding | root `CLAUDE.md` | Shared rate-limit/cache state across workers, never a hard dependency. | Yes — independently verified: every Redis call site (`core/rate_limiter.py`, `core/cache.py`) falls back to in-memory/local-disk on any Redis error or absent `REDIS_URL` | HIGH (quality/ops agent traced the exact fallback logic) |
| `ThreadPoolExecutor` for parallelism, not a broker | Accepted, binding | root `CLAUDE.md` | Rejects Celery/Kafka/RabbitMQ/SQS/Temporal/any broker. | Yes — confirmed: every parallel fan-out in the codebase (analysis's 6 tasks, market-picks' 6 phases, SME/screener's per-stock fetch, portfolio's broker sync) uses a local `ThreadPoolExecutor`; no message-broker client library is a dependency | HIGH |

| Magic-link auth, no passwords, no OAuth | Accepted | `backend/auth.py` | First successful magic-link click *is* account creation; only SHA-256 hashes persisted for magic links/sessions/API keys. | Yes | HIGH (backend-core agent) |
